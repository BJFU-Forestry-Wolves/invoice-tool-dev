报销附件整理与订单日期识别工具
==================================

本版本是图形界面程序，可整理并重命名报销附件，也可从订单截图识别下单日期并生成 Excel 报告。
电脑不需要安装 Python。
已启用 Windows Per-Monitor V2 高 DPI 适配，支持 2K/4K 和多显示器缩放。
附件、CSV、Excel 结果和 OCR 缓存均应保存在开发仓库之外，不会上传到 Git。

一、附件目录结构

附件根目录\
├─ 发票\
└─ 订单截图\

附件文件名应为：编号.扩展名 或 编号(数字).扩展名。

二、整理并重命名附件

1. 双击 invoice_attachment_tool.exe。
2. 选择 CSV 数据表。
3. 选择包含“发票”和“订单截图”子目录的附件根目录。
4. 选择结果保存目录。
5. 按需要修改“文件命名格式”。
6. 保持勾选“仅预演”，点击“开始处理”。
7. 检查日志确认匹配结果。
8. 取消勾选“仅预演”，再次点击“开始处理”完成正式复制。

选择 CSV 后，程序会自动把结果目录设为 CSV 同目录下的“重命名结果”。
如果同目录存在“CSV文件名_附件”文件夹，也会自动识别为附件根目录。

预演不会复制文件，也不会生成 summary.csv。正式处理前会再次确认。

三、识别订单下单日期

1. 选择 CSV、附件根目录和结果保存目录。
2. 在“处理任务”中勾选“识别订单下单日期并生成 Excel”。
3. 默认勾选“仅处理新增或变化文件”，程序会复用本地缓存。
4. 如需忽略缓存，勾选“强制重新识别”。
5. 点击“开始处理”，界面会显示扫描、OCR、规则和 Excel 阶段进度。
6. 完成后可直接打开 Excel 报告。

Excel 报告包含：订单日期汇总、附件识别明细、待人工复核、运行统计。
日期字段为真实 Excel 日期；源文件列可点击打开附件；黄色或红色结果需要人工复核。
程序不会用付款、发货、完成、退款或开票日期代替下单日期。

四、自定义文件名

默认格式：

  {编号}_{上传人}_{用途}_{金额}_{附件标记}

可使用：{编号}、{上传人}、{用途}、{金额}、{附件标记}、{附件类型}、{序号}、{总数}。
程序会自动保留原附件扩展名。建议格式中包含 {编号} 和 {附件标记}，避免文件重名。

五、命令行（开发与排查）

  python order_date_report_cli.py --csv <CSV路径> --attach-root <附件根目录> --output-dir <结果目录>

结果目录和缓存路径必须位于 Git 仓库之外。命令行同时生成 Excel 报告和可追溯的 JSON 规则结果。

P4 全量验证可使用历史扫描摘要自动生成仓库外的最小验证清单：

  python p4_full_validation_cli.py --scan-summary <扫描摘要.json> --golden-workbook <人工标注.xlsx> --attach-root <附件根目录> --output-dir <结果目录> --cache <OCR缓存.sqlite3>

最小验证清单只用于日期识别验收，上传人、用途和金额为占位值。正式业务报告必须使用原始 CSV 运行 order_date_report_cli.py。
