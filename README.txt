报销附件整理工具（最小验证版）
================================

本版本是图形界面程序，用于整理并重命名报销附件。
电脑不需要安装 Python。
已启用 Windows Per-Monitor V2 高 DPI 适配，支持 2K/4K 和多显示器缩放。

一、附件目录结构

附件根目录\
├─ 发票\
└─ 订单截图\

附件文件名应为：编号.扩展名 或 编号(数字).扩展名。

二、使用步骤

1. 双击 invoice_attachment_tool.exe。
2. 选择 CSV 数据表。
3. 选择包含“发票”和“订单截图”子目录的附件根目录。
4. 选择结果保存目录。
5. 按需要修改“文件命名格式”。
6. 保持勾选“仅预演”，点击“开始处理”。
7. 检查日志确认匹配结果。
8. 取消勾选“仅预演”，再次点击“开始处理”完成正式复制。

选择 CSV 后，程序会自动把结果目录设为 CSV 同目录下的“重命名结果”。
如果同目录存在“CSV文件名_附件”文件夹，也会自动识别为附件根目录。

预演不会复制文件，也不会生成 summary.csv。正式处理前会再次确认。

三、自定义文件名

默认格式：

  {编号}_{上传人}_{用途}_{金额}_{附件标记}

可使用：{编号}、{上传人}、{用途}、{金额}、{附件标记}、{附件类型}、{序号}、{总数}。
程序会自动保留原附件扩展名。建议格式中包含 {编号} 和 {附件标记}，避免文件重名。
